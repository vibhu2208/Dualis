# The Dualis - Luxury Real Estate Website

A stunning, fully-responsive luxury real estate website for **The Dualis** by Kreeva India & Shapoorji Pallonji Real Estate, located in Sector 46, Gurugram.

## ✨ Features

### 🎨 Design & UX
- **Luxury Theme**: Charcoal black, white, gold, and champagne beige color scheme
- **Premium Typography**: Playfair Display for headings, Poppins for body text
- **Full-Width Responsive Layout**: Optimized for desktop, tablet, and mobile
- **Smooth Animations**: GSAP-powered scroll animations and transitions
- **Interactive Elements**: Hover effects, parallax scrolling, and smooth transitions

### 🏗️ Sections Included

1. **Hero Section**
   - Full-screen video background
   - Compelling headlines and call-to-action buttons
   - Animated scroll indicator

2. **About The Project**
   - Project overview and developer collaboration
   - Key statistics (198 residences, 2 towers, 3-4 BHK options)
   - Architecture showcase

3. **Project Highlights**
   - Interactive grid with hover animations
   - Premium features showcase (architecture, layouts, finishes, etc.)

4. **Location Advantage**
   - Interactive location map
   - Key landmarks and connectivity (Medanta, NH-8, IKEA, etc.)
   - Animated location markers

5. **World-Class Amenities**
   - Image carousel with auto-play
   - Clubhouse, fitness center, spa, and pool showcases

6. **Luxurious Interiors**
   - Elegant image grid with overlay effects
   - Living spaces, master suites, kitchens, and bathrooms

7. **Developers' Legacy**
   - Kreeva India and Shapoorji Pallonji brand stories
   - Company logos and heritage information

8. **Gallery & Master Plans**
   - Lightbox gallery functionality
   - High-quality project imagery

9. **Contact & Registration**
   - Lead capture form with validation
   - Registration interest functionality

10. **Footer**
    - HARERA registration details
    - Contact information and social links
    - Legal disclaimers

### 🚀 Interactive Features

## 🚀 Getting Started

### Option 1: Simple HTTP Server (Recommended)
```bash
# Navigate to project directory
cd "c:\Users\100acress.com\Documents\GitHub\Dualis"

# Start local server (Python 3)
python -m http.server 8000

# Or with Python 2
python -m SimpleHTTPServer 8000

# Or using Node.js
npx http-server -p 8000
```

Then open `http://localhost:8000` in your browser.

### Option 2: Direct File Opening
Simply open `index.html` in your web browser. However, some features may be limited due to CORS restrictions.

## 🔧 Customization

### Updating Content
1. **Project Details**: Edit the HTML sections in `index.html`
2. **Styling**: Modify colors and fonts in `styles.css`
3. **Animations**: Adjust GSAP settings in `script.js`
4. **Assets**: Replace images in the `public/` directory

### Adding New Sections
1. Add HTML structure to `index.html`
2. Style with CSS in `styles.css`
3. Add animations in `script.js` if needed
